# «Шарм» — демонстрационный сайт интерьерного ателье

Индивидуальный **неофициальный демонстрационный концепт** студии штор «Шарм» (Липецк). Разработчик: [@milmak11](https://t.me/milmak11).

## Посмотреть без установки

Самый удобный способ: открыть **`preview-offline.html`** двойным нажатием. Файл полностью автономный: в него встроены CSS, JavaScript и все SVG-иллюстрации; интернет не требуется. Действуют переключатели и фильтры, просмотр интерьеров, конфигуратор, фото предпросмотра, создание текста заявки. Буфер обмена может запрашивать разрешение браузера (в обычном браузере через HTTPS работает штатно).

`index.html` — основная файловая версия для сайта (рядом должны находиться `styles.css`, `script.js` и папка `assets/`).

## Как выложить на Vercel

Это статический сайт **HTML/CSS/JS без npm, React и сборки**. Публикация через GitHub:

1. Распакуйте ZIP.
2. Создайте GitHub-репозиторий и загрузите содержимое папки `Sharm_Lipetsk_Website_Vercel` так, чтобы `index.html` лежал в корне.
3. В Vercel выберите **Add New → Project** и подключите репозиторий.
4. **Framework Preset: Other**, Build Command не нужен, Output Directory оставьте без значения.
5. Запустите Deploy. Пример названия: `sharm-lipetsk-demo` (доступность адреса не проверялась).

Либо загрузите папку со всеми файлами на любой обычный статический хостинг.

## Что работает

- Адаптивная страница с интерьерными SVG в самостоятельной цветовой палитре.
- Галерея-шоукейс: фильтр по комнатам, полноэкранный просмотр эскизов и переход к соответствующему подбору.
- Иллюстрация проекта мансарды из описания поста компании от 13 ноября 2026 года; не фотография заказа.
- Конфигуратор: гостиная/спальня/кухня/детская, портьеры и тюль/римские/лёгкие занавеси, пять оттенков, вид окна, ширина и высота, светозащита, бюджет, комментарий.
- Изменяемая SVG-схема окна, которая реагирует на выбор типа штор, комнаты, оттенка, затемнения и мансарды.
- Выбор ткани из четырёх условных образцов, включение предпочтения в текст заявки.
- Четыре вида карнизов с интерактивной иллюстрацией и пояснениями.
- Локальный просмотр выбранной фотографии JPG/PNG/WebP до 8 МБ. Файл остаётся в браузере.
- Валидация размеров и копирование подробного запроса в буфер обмена.
- Ссылки для самостоятельного обращения через VK и WhatsApp; телефонные ссылки для звонка.
- Открывающиеся FAQ, мобильное меню, анимации появления и поддержка `prefers-reduced-motion`.
- Небольшая рамка «Разработчик @milmak11» в подвале.

## Что является демонстрацией

Проект не является официальным ресурсом компании. Нарисованные нами SVG-интерьеры и ткани — **эскизы и иллюстрации**, а не фотографии выполненных работ или образцы реального складского ассортимента. Единственный конкретный заказ описывается по публичной публикации студии о мансардном этаже от 13.11.2026, без копирования фотографий клиента. Сведения о рейтинге и условиях могут измениться; подтверждаются перед коммерческой публикацией. Цены, отзывы, сроки и гарантийные обещания **не выдуманы**.

Заявки не отправляются на сервер, нет аналитики, базы данных, регистрации и сбора контактных данных. Фото нельзя автоматически отправить вместе с текстом — пользователь прикладывает его самостоятельно в VK/WhatsApp.

## Что нужно от владельца для официального сайта

- Подтвердить адрес, режим работы, номера телефонов и все рекламируемые услуги.
- Разрешить размещение настоящих интерьерных фотографий, предоставить портфолио.
- Подтвердить перечень тканей, наличие конкретных коллекций, допустимые способы пошива и виды карнизов.
- Уточнить актуальные сроки, стоимость замера, монтажа и доставки.
- Согласовать обработку персональных данных при переходе к реальной форме заказа.
- Заменить пометку демоверсии и снять `noindex` **только после согласования**.
